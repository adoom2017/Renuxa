# 当前实现状态

截至 2026-09-09，仓库具备以下可运行能力：

- Web 和 Tauri 桌面端共用订阅管理界面。
- Rust API 提供认证、订阅、账单、通知设置、图标和汇率接口。
- Worker 生成续费提醒与预计账单，并支持应用内和 Telegram 通知。
- 微信网关支持 Web 二维码绑定、私聊文字和截图录入、补充追问、确认入库、
  幂等重试，以及自然语言查询已经发送到期提醒的订阅。
- Docker 文件集中在 `docker/`，`npm run debug` 可构建、启动、等待健康检查、
  执行测试并持续输出日志。
- GitHub Actions 使用 `docker/Dockerfile.web` 和 `docker/Dockerfile.server`
  发布 amd64、arm64 镜像。

真实微信扫码、模型文字识别和容器 API 已在本地调试流程中验证；自动化测试不代表
所有模型提供商都支持图片识别。发布前仍需以目标模型和实际微信账号完成文字、截图、
相对日期、重复确认、重新登录和服务重启验收。
